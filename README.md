## Organização da equipe

- components/: elementos reutilizáveis.
- pages/: páginas completas do site.
- assets/: imagens, ícones e outros arquivos visuais.
- styles/: CSS global e variáveis de estilo.

## Regras

- Cada integrante trabalha no próprio branch.
- Manter os arquivos organizados nas pastas correspondentes.
- Reutilizar componentes existentes para evitar duplicação.
- Integrar alterações ao `main` após revisão da equipe.
- Avisar a equipe antes de modificar arquivos compartilhados.
